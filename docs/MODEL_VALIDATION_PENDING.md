这也是本次失败 trial 保存的调用形式。模板不覆盖模型，也不使用绕过审批或沙箱的参数。模型与身份配置沿用执行环境；真实使用的工具与模型身份以可观察运行记录为准，不能由 CLI 版本或配置存在推定模型已完成请求。

实际命令、参数和返回码见 [研究循环](RESEARCH_LOOP.md#公开-jsonl-任务的有限验收入口)。当前没有运行新的 campaign，也没有实测该入口完整的两轮模型、确认与交付路径；预检通过同样不证明 app-server、网络或模型可用。入口即使返回执行完成，仍将 G3 标记为待证据审查，需人工核对真实反馈链。
