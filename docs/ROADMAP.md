## 4. 自适应研究线与分支组合

当前父代策略是 best-valid-search，方向是配置中的固定 lanes 轮转；编码 worker 在当前线内利用历史提出假设。自动 spawn 新线、按证据动态分配线预算和合并 winning branches 均未实现。

以后增加这些机制时，保存方向生成依据、预算变更和全部来源候选。组合后按同一合同重新完整评价，记录接口或状态冲突的处理。先比较它们是否增加单位预算内的有效候选或减少等待，再决定是否加入并行执行器；新增能力不能只靠多出 lane 标签验收。

## 5. 改进研究方法

积累足量真实轨迹后，比较父代选择、历史读取、故障定位和方向分配策略。固定任务分布与总资源，测量新策略的有效候选率、最终效果和研究成本。在未参与策略调整的任务上检验迁移；一次任务上的改进不能直接视为研究能力普遍提升。

这一阶段才讨论研究器自身的递归改进：新的研究方法必须产生可复测的下游收益，并保留原研究器作为可恢复对照。当前 v0.2 的控制工程和单任务 CPU 结果不能关闭这一阶段。
